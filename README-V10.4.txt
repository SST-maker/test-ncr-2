NCR Portfolio V10.4 — SCREEN STAGE

Principe corrigé :
- le projet actif est affiché en grand DANS l’écran du robot pendant toute sa phase active ;
- l’écran du ventre se déploie en grand pour rendre le projet lisible ;
- au projet suivant seulement, l’ancien projet se rétracte vers le ventre ;
- le ventre s’ouvre pendant le rangement puis la miniature rejoint la mémoire interne ;
- les projets ne flottent donc plus comme de grandes cartes indépendantes.
