NCR Portfolio V10.3 — Belly Vault

- Le Magnetic Stack ne se ferme plus sur l’écran du robot.
- Le ventre du robot devient une trappe / mémoire interne.
- Au scroll, la trappe s’ouvre progressivement.
- Chaque projet se miniaturise, plonge en profondeur dans le ventre puis disparaît derrière le cadre.
- Une carte mémoire correspondante apparaît à l’intérieur et s’empile avec les précédentes.
- Les projets restent visibles dans le ventre sous forme de pile.
- Le carrousel Azzera et le reste de la V10.2 sont conservés.
